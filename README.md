# Консольный и графический акинатор
Данный проект является реализацией Акинатора, сделанного на основе структуры данных - [бинарное дерево](https://ru.wikipedia.org/wiki/%D0%94%D0%B2%D0%BE%D0%B8%D1%87%D0%BD%D0%BE%D0%B5_%D0%B4%D0%B5%D1%80%D0%B5%D0%B2%D0%BE).

## Концепция реализации
Построение акинатора на основе бинарного дерева позволяет хранить в узлах дерева вопросы, а в листьях возможные загаданные варианты. Отвечая на вопросы, пользователь доходит до искомого объекта (если он есть в дереве).

## Доступные функции и возможности
Во время работы программы можно:

- Неограниченное число раз загружать и сохранять полученную базу данных.
>[!WARNING]
>Для работы с программой необходимо загружать непустую базу. Добавление первого элемента во время работы программы невозможно, то есть необходимо загружать файл хотя бы с именем одного объекта. Пример содержимого простейшего файла запуска: (object(nil)(nil)). object - текст, ограниченной длины (255 символов). Избегайте использования символа " в object, так как возможны сбои в работе графического дампа базы данных.

- Искать элемент (если элемент не найден, его можно добавить).

- Строить путь до элемента (если элемент не существует выведется сообщение об ошибке).

## Принцип работы с консольным акинатором
При запуске программы появляется меню:
```C
Akinator
0 - start searching
1 - save database
2 - open database
3 - definition
q - exit
```
Далее нужно загрузить базу, введя `2` и нажав `ENTER`, появится строка `File name to open:`. Введите имя файла с которым хотите работать, после чего нажмите `ENTER`.
>[!NOTE]
>Если не найден файл с таким именем, то выведется сообщение `ERROR: Failed to open file famous` и `People.txtERROR: can't load tree`.

После введения корректного имени можно: искать элемент (0), [сохранять базу](###Сохранение-базы-данных) (1), [строить путь до элемента](###Построение-пути-до-элемента) (3), [загружать новую базу данных](###Загрузка-новой-базы) (2) или [завершать работу программы](###Завершение-работы-программы) (q)

### Сохранение базы данных
Введите `1` и нажмите `ENTER`, появится строка `File name to open:`. Введите имя файла и нажмите `ENTER`. Всё, база сохранена.

### Построение пути до элемента
Введите `3` и нажмите `ENTER`, появится строка `Name of the target object:`. Введите искомый объект, после чего нажмите `ENTER`. Получите что-то такое `Не a mammal?->Не a bird?->Не an insect or arachnid?->Не a marine creature that lives in the ocean?->Не a legless reptile that slithers on the ground?->a slow-moving reptile with a hard shell on its back?->`.
>[!NOTE]
>Если не найден такой объект, то выведется сообщение `ERROR: can't find dolphin`.

### Загрузка новой базы
Введите `2` и нажмите `ENTER`, появится строка `File name to open:`. Введите имя файла с которым хотите работать, после чего нажмите `ENTER`.
>[!NOTE]
>Если не найден файл с таким именем, то выведется сообщение `ERROR: Failed to open file famousPeople.txt` и `ERROR: can't load tree`.

### Завершение работы программы
Введите `q` и нажмите `ENTER`. Всё, программа завершилась.
>[!NOTE]
>Не забудьте сохранить изменения, так как автоматического сохранения не предусмотренно.

## Компиляция и установка необходимой утилиты
>[!NOTE]
>Проект создавался исключительно под Linux

Для графического дампа дерева необходимо скачать Graphiz:
```bash
sudo apt update
sudo apt install graphviz
```
Для работы с графическим акинатором необходимо установить raylib
```bash
sudo apt update
sudo apt install build-essential git cmake libasound2-dev mesa-common-dev libx11-dev libxrandr-dev libxi-dev xorg-dev libgl1-mesa-dev libglu1-mesa-dev
```

```bash
cd ~
git clone https://github.com/raysan5/raylib.git
cd raylib
```

```bash
cd src
make PLATFORM=PLATFORM_DESKTOP
sudo make install
```

Для компиляции консольного акинатора использовать команду
```bash
scripts/buildAkinator.sh
```

Для компиляции консольного акинатора использовать команду
```bash
scripts/buildAkinatorInWindow.sh
```
